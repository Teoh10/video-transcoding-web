# Repository working instructions

- State assumptions and a short verification plan before making code changes.
- Keep changes focused on the requested step. Do not refactor unrelated code.
- Verify each change with a relevant test or check, and report what remains unverified.
- Keep `WORK_IN_PROGRESS.md` updated while a task is unfinished. Record the current step, what changed, what was checked, and what remains.
- When the task is fully resolved and verified, remove `WORK_IN_PROGRESS.md`. Keep this `AGENTS.md` file.
